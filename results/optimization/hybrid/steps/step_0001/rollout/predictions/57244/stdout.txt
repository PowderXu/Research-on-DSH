{"answer":"This is an enterprise/organization policy restriction. GitHub Docs state that if a more restrictive default is set at the enterprise level, organizations cannot select the more permissive (Read and write) default for repositories; organization repo settings inherit the enterprise choice and the permissive option is disabled. To allow workflows write access you must have an enterprise owner change the enterprise default to a permissive setting (or change the org-level default if the enterprise allows it). Additionally, repository-level write permission for GITHUB_TOKEN can be adjusted in workflow files by users with write access and the “Send write tokens to workflows from pull requests” option affects whether workflows from PRs get write tokens.
